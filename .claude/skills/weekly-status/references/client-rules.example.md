# Client rules

Rules that only apply to this client: names, wording, things they don't want to see. The general rules are in `rules.md`; these add to them, and win where they disagree.

Copy this file to `client-rules.md` (gitignored), then replace the examples with your own, or delete them. An empty file is fine. `improve-skills` adds lines here when a correction is specific to this client.

## Who attends

- EXAMPLE: <Name> attends the meeting, so never name them as a recipient or third party ("shared with <Name>", "<Name> to decide"). Write "shared", "pending decision", "feedback received".

## Leave out

- EXAMPLE: follow-ups that only say the client still has to review something ("<Name> to review the reports").
- EXAMPLE: a blocker repeated under an item when it already has its own item (e.g. test devices).

## Wording

- EXAMPLE: call the product "<product name>", never by its internal code name.
